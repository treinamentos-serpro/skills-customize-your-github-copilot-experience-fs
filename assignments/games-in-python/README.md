
# 📘 Assignment: Hangman Game

## 🎯 Objetivo

Practice string manipulation, loops, conditionals, and user input by building a classic hangman game in Python.

## 📝 Tarefas

### 🛠️ Select a Secret Word

#### Description
Create a list of words and choose one at random for each game round. Then display the hidden word using underscores and update it as the player guesses letters.

#### Requirements
The completed program must:

- Use a predefined list of words
- Choose a random word for each round
- Show the hidden word as underscores or blanks
- Accept letter guesses from the user
- Update the display with correct guesses

### 🛠️ Track Guesses and Lives

#### Description
Keep track of the letters already guessed, the number of incorrect attempts, and the remaining lives during the game.

#### Requirements
The completed program must:

- Store guessed letters
- Count incorrect guesses
- Show remaining lives and failed attempts
- Prevent repeated guesses
- End the game when the player wins or loses

### 🛠️ Win or Lose Conditions

#### Description
Decide when the player has guessed the word successfully or run out of attempts, and print a final result message.

#### Requirements
The completed program must:

- Detect when all letters are revealed
- Detect when the player has no lives left
- Print a clear victory or defeat message
- Ask whether the player wants to play again
